AYCE CONFERENCE FLIPBOOK — QUICK START

This folder contains:
- index.html                 The AYCE branded PDF flipbook viewer
- conference-program.pdf     Your uploaded 2026 conference program

IMPORTANT
The viewer expects the PDF filename to be exactly:
conference-program.pdf

HOW IT WILL DISPLAY
- Page 1: cover displayed by itself
- Pages 2–47: 23 facing-page spreads on desktop
- Page 48: back cover displayed by itself
- On phones: one page at a time, with swipe navigation

FREE HOSTING
This package is prepared for GitHub Pages. The repository must be PUBLIC for the free GitHub Pages plan.
The PDF will therefore be publicly accessible to anyone with the link.

You do not need to edit the code.
When you replace the program in a future year, upload the new PDF using the same filename:
conference-program.pdf

SQUARESPACE
After GitHub Pages is enabled, embed the published address in a Squarespace Code Block using an iframe.
The exact embed snippet and step-by-step instructions will be provided separately.

NOTE
The viewer loads PDF.js from a public CDN, so visitors need an internet connection.
